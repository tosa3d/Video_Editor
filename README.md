# بُرش

یک برنامه رومیزی فارسی برای تقسیم یک ویدیو به چند کلیپ مستقل. پردازش فایل کاملاً روی دستگاه انجام می‌شود و FFmpeg همراه برنامه قرار دارد.

## امکانات

- انتخاب یک فایل ویدیویی محلی
- پخش و توقف با `Space`
- حرکت یک فریم جلو با `.` و یک فریم عقب با `,`
- ثبت نقطه برش با `Z`
- خط زمان تعاملی و فهرست کلیپ‌ها
- حذف نقطه‌های برش
- تنظیم FPS برای حرکت دقیق فریم‌به‌فریم
- خروجی دقیق هر بخش به یک فایل MP4 جداگانه با H.264 و AAC
- ساخت نسخه‌ی برعکس هر کلیپ هنگام خروجی (تصویر و صدا از آخر به اول؛ گزینه‌ی کنار FPS، پیش‌فرض روشن)

## اجرای حالت توسعه

پیش‌نیاز: Node.js نسخه 20 یا جدیدتر.

```powershell
npm install
npm run dev
```

## بررسی و ساخت

```powershell
npm run typecheck
npm run lint
npm run build
```

برای ساخت نصب‌کننده ویندوز:

```powershell
npm run dist
```

فایل نصب‌کننده در پوشه `release` ساخته می‌شود.

## روش استفاده

1. «انتخاب ویدیو» را بزنید و یک فایل باز کنید.
2. با خط زمان یا کلیدهای میانبر به فریم دلخواه بروید.
3. با `Z` نقطه برش ثبت کنید. هر نقطه، یک مرز جدید بین کلیپ‌ها می‌سازد.
4. در صورت نیاز FPS نمایش‌داده‌شده را با نرخ فریم فایل یکسان کنید.
5. «خروجی کلیپ‌ها» را بزنید و پوشه مقصد را انتخاب کنید.

فایل‌ها با الگوی `video_part_01.mp4`، `video_part_02.mp4` و به همین ترتیب ذخیره می‌شوند. اگر گزینه‌ی «نسخه‌ی برعکس» روشن باشد، کنار هر کلیپ فایل `video_part_01_reverse.mp4` هم ساخته می‌شود. فیلتر برعکس‌کردن FFmpeg کل کلیپ را در حافظه نگه می‌دارد؛ برای کلیپ‌های خیلی بلند با کیفیت بالا رم زیادی لازم است. خروجی دوباره رمزگذاری می‌شود تا محل برش با فریم انتخاب‌شده هماهنگ باشد.
